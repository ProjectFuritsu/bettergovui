# Security

This kit is meant for government websites, so security problems matter.

## Reporting a problem

**Please don't report security problems in a public issue.** Instead, use GitHub's private reporting:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what someone could do with it.

Only the maintainers can see your report. We'll reply as soon as we can and let you know when it's fixed.

## What counts

For example: a way to run someone else's code through a component (cross-site scripting), a component that leaks
what people type (like a password or an ID number), or anything in the code examples that would be unsafe to copy.
